## Featured project

### [Golfinho — Cross-platform Security Research](https://github.com/LourencoGHJ/linux-security-checker)

A Python research prototype for local system and network inspection across **Windows and Linux**.

- Host and operating-system profiling.
- Network inventory: interfaces, IP addresses, gateways and DNS.
- Initial Linux security checks and Windows Firewall collection.
- Local dashboard and HTML/JSON reporting.
- Automated tests and GitHub Actions.

<sub>Read-only by design. Early-stage research prototype — not a complete vulnerability scanner or EDR.</sub>
