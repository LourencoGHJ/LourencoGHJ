## 04 / Engineering approach

I aim to follow a disciplined workflow when investigating a technical problem:

| Stage | What it means |
|:--|:--|
| **Understand** | Define the system, context and expected behaviour. |
| **Inspect** | Collect relevant information using appropriate tools. |
| **Analyse** | Separate raw observations from assumptions and conclusions. |
| **Validate** | Reproduce results, test edge cases and check limitations. |
| **Communicate** | Document evidence, impact and uncertainty clearly. |
| **Improve** | Make changes deliberately and verify their effect. |

### Principles I value

- **Evidence first** — conclusions should be traceable to observations.
- **Least privilege** — use only the access required for the task.
- **Safe by design** — prefer controlled, non-destructive and read-only inspection where appropriate.
- **Reproducibility** — make checks and results understandable and repeatable.
- **Continuous learning** — revisit assumptions, learn from failures and improve the implementation.
